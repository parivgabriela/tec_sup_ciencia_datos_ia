# Procesamiento del Aprendizaje Automático

## Información de la Materia

- **Institución:** IFTS 24
- **Año:** Segundo año
- **Docente:** D'astolli
- **Modalidad:** Trabajos prácticos grupales

## Descripción

Esta materia aborda los conceptos fundamentales del aprendizaje automático (Machine Learning), cubriendo diferentes algoritmos y técnicas para el procesamiento y análisis de datos. Los trabajos prácticos fueron desarrollados de manera grupal, aplicando métodos de aprendizaje supervisado a datasets reales.

## Contenido del Repositorio

Este repositorio contiene los laboratorios y trabajos prácticos desarrollados durante el cursado de la materia:

### Trabajos Prácticos

#### **TP N°1 - Regresión Lineal y Polinomial**
- **Archivo:** `TP_N1_Regresion_Lineal_y_Polinomial.ipynb`
- **Descripción:** Implementación y análisis de modelos de regresión lineal simple y múltiple, así como regresión polinomial
- **Contenido:**
  - Introducción a la regresión lineal
  - Implementación de regresión lineal simple
  - Regresión lineal múltiple
  - Regresión polinomial


#### **TP N°2 - Regresión Logística**
- **Archivo:** `TP_N2_Regresion_Logistica_GRUPO_8.ipynb`
- **Grupo:** Grupo 8
- **Descripción:** Desarrollo de un modelo de clasificación binaria utilizando regresión logística
- **Caso de estudio:** Predicción de aprobación de exámenes basada en horas de estudio
- **Contenido:**
  - Implementación de regresión logística
  - Evaluación del modelo (accuracy, precision, recall)
  - Interpretación de resultados
  - Curva ROC y matriz de confusión

#### **TP N°3 - Árboles de Decisión**
- **Archivo:** `TP_N3_Arbol_de_Decision_Titanic_Grupo_8.ipynb`
- **Grupo:** Grupo 8
- **Descripción:** Implementación de algoritmos de árboles de decisión aplicados al famoso dataset del Titanic
- **Caso de estudio:** Predicción de supervivencia de pasajeros del Titanic
- **Contenido:**
  - Preprocesamiento del dataset del Titanic
  - Análisis exploratorio de datos
  - Construcción de árboles de decisión
  - Visualización del árbol resultante
  - Evaluación y métricas de performance

## Algoritmos Implementados

1. **Regresión Lineal Simple y Múltiple**
   - Método de mínimos cuadrados
   - Análisis de residuos
   - Métricas: R², RMSE, MAE

2. **Regresión Polinomial**
   - Transformación de características
   - Overfitting y underfitting
   - Validación cruzada

3. **Regresión Logística**
   - Clasificación binaria
   - Función sigmoide
   - Métricas: Accuracy, Precision, Recall, F1-Score

4. **Árboles de Decisión**
   - Criterios de división (Gini, Entropy)
   - Poda de árboles
   - Interpretabilidad del modelo

## Metodología

Cada trabajo práctico sigue una estructura similar:

1. **Análisis Exploratorio de Datos (EDA)**
   - Comprensión del dataset
   - Estadísticas descriptivas
   - Visualizaciones

2. **Preprocesamiento**
   - Limpieza de datos
   - Tratamiento de valores faltantes
   - Transformación de variables

3. **Modelado**
   - Implementación del algoritmo
   - Ajuste de hiperparámetros
   - Entrenamiento del modelo

4. **Evaluación**
   - Métricas de performance
   - Validación cruzada
   - Análisis de resultados

5. **Conclusiones**
   - Interpretación de resultados
   - Limitaciones del modelo
   - Posibles mejoras
