## Descripción

Este repositorio contiene el material práctico desarrollado durante el curso de **Minería de Datos**, donde se abordan conceptos fundamentales de análisis y exploración de datos utilizando Python y sus principales librerías científicas.

El curso cubre desde fundamentos estadísticos hasta técnicas avanzadas de web scraping, proporcionando las herramientas necesarias para extraer, procesar y visualizar información de diversas fuentes de datos.

## Contenido del Repositorio

### [Repaso_visualizacion_datos_estadistica_descriptiva/](./Repaso_visualizacion_datos_estadistica_descriptiva/)

**Fundamentos Estadísticos y Visualización**

Esta carpeta contiene notebooks que cubren los conceptos base necesarios para el análisis de datos:

#### [1 - Estadística.ipynb](./Repaso_visualizacion_datos_estadistica_descriptiva/1%20-%20Estadística.ipynb)
Repaso integral de estadística descriptiva incluyendo:
- Medidas de tendencia central (media, mediana, moda)
- Medidas de dispersión (varianza, desviación estándar)
- Distribuciones de frecuencia
- Conceptos básicos de probabilidad

#### [2 - Exploración visual.ipynb](./Repaso_visualizacion_datos_estadistica_descriptiva/2%20-%20Exploración%20visual.ipynb)
Técnicas de exploración visual de datos para identificar patrones, outliers y tendencias mediante gráficos estadísticos básicos.

#### [3 - Correlaciones.ipynb](./Repaso_visualizacion_datos_estadistica_descriptiva/3%20-%20Correlaciones.ipynb)
Análisis de correlaciones entre variables:
- Coeficiente de correlación de Pearson
- Matrices de correlación
- Visualización de correlaciones
- Implementación práctica usando librerías de Python

#### [4 - NumPy.ipynb](./Repaso_visualizacion_datos_estadistica_descriptiva/4%20-%20NumPy.ipynb)
Repaso completo de la librería NumPy cubriendo:
- Arrays multidimensionales
- Operaciones matemáticas vectorizadas
- Indexación y slicing
- Funciones estadísticas básicas

#### [5 - Pandas.ipynb](./Repaso_visualizacion_datos_estadistica_descriptiva/5%20-%20Pandas.ipynb)
Manejo de datos estructurados con Pandas:
- DataFrames y Series
- Limpieza y transformación de datos
- Agregaciones y agrupaciones
- Manejo de datos faltantes

#### [6 - Introducción Matplotlib.ipynb](./Repaso_visualizacion_datos_estadistica_descriptiva/6%20-%20Introducción%20Matpotlib.ipynb)
Fundamentos de visualización con Matplotlib:
- Gráficos básicos (líneas, barras, histogramas)
- Personalización de gráficos
- Subplots y layouts
- Exportación de gráficos

#### [8 - Seaborn.ipynb](./Repaso_visualizacion_datos_estadistica_descriptiva/8%20-%20Seaborn.ipynb)
Visualizaciones estadísticas avanzadas con Seaborn:
- Gráficos de distribución
- Gráficos de relación entre variables
- Mapas de calor para correlaciones
- Personalización de estilos

- Realizar análisis exploratorio de datos de forma sistemática
